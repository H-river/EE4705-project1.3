# Changes to Student A's and Student C's code (night run + rounds 2–3)

This file lists every commit on branch `e2e` that changed A's code (`perception/`) or C's code (`executor/student_c.py`), plus the shared-backbone edits that came with them. It is the record for A and C. We made these changes without asking you first, so please review them. Drop any commit you disagree with with `git revert <hash>`. Each commit is self-contained and has its own tests.

**Kind:**
- **behavioural**: the module does or decides something different, even when its inputs are valid.
- **robustness**: a valid input gives the same result as before; only a malformed or failing input (a bad VLM reply, a provider refusal) is now handled instead of crashing.

Stage 2 items (2.x) came from a code review in the night-run plan, not from a failing trial. "Round N" items came from the trial named in the "trial" column. All paths are relative to the repo root; run outputs are under `runs/night/` (git-ignored).
